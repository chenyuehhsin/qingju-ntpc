# 青聚新北

青年安居 × 就業 × 交通機會推薦

## MVP
輸入青年偏好條件，整合新北居住、就業與交通資料，
推薦適合落腳的行政區，並提供 AI 解釋。

## Core dimensions
- Housing
- Employment
- Transportation
