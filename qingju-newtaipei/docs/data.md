# 資料檔案

| 路徑 | 用途 |
|---|---|
| `data/raw/new_taipei_jobs.csv` | 依行政區與職類彙整公開職缺 |
| `data/processed/district_summary.csv` | 新北 29 區就業、租屋及青年人口摘要 |
| `data/processed/data_profile.json` | 資料日期、筆數、門檻及處理口徑 |
| `data/processed/new_taipei_districts.geojson` | 新北行政區地圖邊界 |

資料來源包括台灣就業通公開職缺、新北市不動產實價登錄租賃案件，以及內政部五歲年齡組人口統計。18–35 歲人口為年齡組推估且依戶籍統計，無法辨識外地戶籍但實際居住於新北的青年。
